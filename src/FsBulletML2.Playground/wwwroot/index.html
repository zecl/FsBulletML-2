補完の使い方

候補は BulletML の DTD から出しているので、その場所に置けるものしか出ない。 打っている途中で XML が壊れていても止まらない。

打つ出るもの
< そこに置ける要素。<action> の中なら fire や wait、 <fire> の中なら direction や bullet
< に続けて何文字か 絞り込み。確定すると <fire> のように入る
タグの中で空白＋何文字か 属性名。確定すると type="" まで入って、カーソルが引用符の中に来る
" 属性値。type なら aim / absolute / relative / sequence
$ に続けて何文字か $rand と $rank。 <wait> や <speed> のように 中身に式を書ける要素の中だけ
Ctrl+Space どこでも明示的に出す。空白を打っただけでは出ないので、属性名はこれが早い

ほかの操作

  • Apply を押すと、書いた XML が弾幕に反映される。 打つたびには反映しない（見ている弾幕が最初に戻ってしまうため）
  • 読めない XML は Apply したときに下のバーへ理由が出る
  • Reset はいま載っている弾幕を最初から。欄の文字は触らない
  • プルダウンで同梱の弾幕を選ぶと、その XML が欄に入る
  • 折りたたみ・検索（Ctrl+F）・ 取り消し（Ctrl+Z）はエディタの標準機能

いま書けるのは XML だけ。sxml や F# の DSL は口だけ開けてある。
