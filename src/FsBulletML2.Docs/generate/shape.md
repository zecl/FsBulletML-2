# 骨格 の 生成（`Generate`・`PatternSpec`・`Exprs`）

仕様（`PatternSpec`）から 式 の 字（`Exprs`）を 引き、BulletML の 木（`Generate`）を 組む。ここ には コード から 外した 実測・経緯・長い 理由 を 置く。

## `Generate`

骨 を N 種類 持って 選ばせる 形 は 採らない。同梱 の 骨 は 78 種類 で 40 種類 が 1 本 だけ の 長い 裾 だが、軸 ごと に 見れば 2〜4 値 に 割れて、掛け算 が 78 に なる。

### `Dir`

CE の 操作（`sequence` / `absolute` …）は 単独 では 値 に ならない。

### `armDir`

`absolute` / `relative` / `aim` を 腕 に 置いた とき、放射 と 扇 が {0, 45 x 8}、狙い が 157 x 8 に 重なって いた。

### `headDir`

`Aiming` だけ で 決めて いた とき、`Spiral` でも 毎波 `absolute 0` に 戻って いて、同じ 向き の リング が 重なる だけ だった。頼んだ 渦 が 渦 に 見えない（実機 で 踏んだ）。

`Spread` を 撃つ側 の 向き（`relative`）を 中心 に して いた とき、敵 は 0 度 なので 自機 と 逆 の 真上 へ 開いて いた。

### 幕 と `Parametrized`

`arm` は 0 度 と 180 度 の 対称 で 組む ので、下向き に 絞った 帯 が 上下 に 割れて 幕 で なくなる。頼まれた 形 の ほう を 優先 する。

### `bullets`

段数 だけ 別 の 弾 を 作る なら 展開 が 有限 に なる。自機 を 追う（`Aiming`）の は 弾 の 側 で、飛びながら 自機 の 方 へ 向き直る。

## `PatternSpec`

### `Curtain`

回る でも 全方位 でも 扇 でも ない ので、4 つ では 表せなかった（jev が conf 0.09 で `spiral` に 落として いた）。

### `Facing`

面 は 縦 で、敵 が 上（240, 80）/ 自機 が 下（240, 600）。型 が 決める 向き は `Spiral` が 回る / `Aimed` が 狙う。

### `Missile`

ミサイル と 言われた なら 狙う のが 本体。

### `Axes`

公開 レコード なので `{ PatternSpec.zero with Speed = 2.0 }` と 書ける。軸 を 足して も 既存 の 呼び出し が 壊れない。閉じる のは `create` 1 か所 だけ で、そこ を 通らない と `PatternSpec` に ならない。

### `PatternSpec`

公開 すると `{ spec with Speed = 99.0 }` が 書けて clamp を 抜ける。中 に `Axes` を 持つ ので、ここ の 読み口 は 1 行 も 増えない。前 は 軸 ごと に `member this.Speed = this.Speed_` を 書いて いた。

### `Ways` と `MAX_WAYS`

`armsExpr` 1 か所 が 読む ので、刻み（`armStep` / `spinExpr` / `curtainStep`）も 一緒 に 追随 する。目 で 数えられる 範囲 を 超えたら「たくさん」と 同じ こと で、固定 の 本数 に すると `$rank` が 1 本 も 効かなく なる。

### `create`

前 は 19 引数 のうち `float` が 10 個 連続 して いて、順 を 間違えて も 通って いた。

## `Exprs`

数 を 直書き せず `$rank` を 含む 式 を 出す。同梱 で `$rank` が 掛かる 先 と 向き（実測）:

| 先 | 向き | 件数 |
|---|---|---|
| speed | 増える | 188 対 18 |
| wait | 減る | 19 対 201 |
| repeat | 増える | 137 対 25 |
| sequence | 減る | 8 対 20 |
| changeDirectionAim | 減る | 1 対 8 |

同梱 193 本 中 184 本（95%）が `$rank` を 式 に 持つ。

### `armsExpr`

3way は どの 難度 でも 3 本 で、増えたら 3way では ない。ここ から 引く 刻み は `armStep` / `spinExpr` / `curtainStep` / `ringStep` / `spreadStep` / `aimStep`。

### `facingExpr`

放射 は 腕 が 2 本 以上 あれば `armStep` が 全周 に 散らす ので、起点 が 右 でも 左 にも 出る。

### `spinExpr`

`sequence` は 波 を 跨いで 累積 する ので、頭 の 1 発 に 刻み を 渡せば リング が 毎波 少しずつ 回る。これ が 無い と 同じ 向き の リング が 重なる だけ で、渦 に 見えない（実機 で 踏んだ）。

### `curtainSpan`

面 は 480x640 で、敵 は (240, 80)、自機 は (240, 600)。横 の 端 まで 届く のに 要る のは `atan(240 / 520)` ＝ 25 度 ほど なので、それ を 少し 越える ところ で 止める。90 度 まで 開いた とき、端 の 弾 が 真横 へ 出て すぐ 画面 から 消え、幕 で なく 扇 に 見えた（実機 で 踏んだ）。

### `curtainStep`

`$rand` で 散らして いた とき、雨 に しか 見えなかった（実機 で 踏んだ）。`sequence` は 直前 の fire の 向き から の 差分（`Step.fs`）。頭 が 毎波 `absolute` で 左端 に 戻る ので、掃く のは 帯 の 中 だけ。

### `laserSpeed`

2 倍 では 速い 弾 と 見分け が つかず、`Speed` 軸 を 上げた だけ に 見えた。

### `missileAccel`

曲がり ながら 加速 する のが ミサイル の 見え方。

### `pauseExpr`

60 コマ 以上 の「間」は 同梱 の 61% が 持つ。

### `waitExpr` と `Rhythm`

同梱 は 1 本 が wait を 中央 3 種類 使い、1 種類 だけ の 本 は 6% しか 無い。

### `BURST_BUDGET`（27）

`lv` を 引く だけ では 足りない。15 / 12 / 9 で 1 発 が 1,620 発 に なり、同時 21,517 発 だった。

### `scatterExpr`

64 の 1/3 乗 が 3.9999… で `floor` が 3 を 返し、予算 64 の つもり が 27 で 動いて いた。

## 較正

| 変異 | 赤 に なった 試験 | 備考 |
|---|---|---|
| 速さ の 係数 を 0.5 -> 0.6 | `端 の組み合わせ 16,384 通り の字 が動かない`・`型 と 名指し の 180 通り の字 が動かない` | 2 点 とも |
| 前方 の 角 を 180 -> 170 | `型 と 名指し の 180 通り の字 が動かない` | 16,384 通り は `Spiral` / `Around` / `Plain` に 固定 して いる ので 当たらない |
| レーザー の 速さ を 3.0 -> 3.1 | `型 と 名指し の 180 通り の字 が動かない` | 同上 |

空振り した 変異（門 の 形 を 変えた 理由）:

- `Cascade` の 枝 を 落とす 変異 は、定義 の 数 だけ 数える 門 では 空振り した（中身 が 空 の 弾 が N + 1 個 出て いて も 通る）。`段 が鎖 で繋がる` は 定義 と 参照 を 数える
- `nestRepeat` の `n <= 1` 変異 は、「flat より 多い」だけ を 見る 門 を 通り抜けた。`段 が入れ子` は N + 2 本 を 固定 する

`GoldenShape` の 個別 の 点 は 51 件 在る が、どれ も「その 性質 が 在る」しか 見て いない。組み直し で 別 の 字 に なって も、性質 が 保たれて いれば 緑 の まま。指紋 は 値 が 1 つ でも 動けば 変わる。赤 に なった とき は 2 通り で、直し が 答え を 変えた か、変える つもり の 直し か。

`speedSeq は 0` の 理由：`sequence` の 速度 0.06 で 弾 が 12 個 に 減った。

`全軸 が読まれる` の 理由：軸 を 9 -> 15 に 増やす 途中 で 3 回 続けて「型 には 在る が 生成器 が 読まない」を 作った（Layers / Depth / Kind / Aiming / Rhythm）。目 で 確かめる のを やめて 数える。
