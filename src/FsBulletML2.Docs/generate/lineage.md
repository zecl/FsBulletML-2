# 系譜（`Lineage`）

弾 が 子 を 生み、子 が また 子 を 生む 系譜 の 生成器。`LineageSpec.create` が 軸（`LineageAxes`）から 仕様 を 組み、`Lineage.generate` が BulletML の 木 に する。

## 根（`Root`）

- `Radial` は 放射。刻み の 半分 ずらす と 自機 の 真上 が 隙間 に なる（見本 は aim 15 / 刻み 30）
- `Bar` は 止まった 発射台 が 回りながら 直線 を 敷く
- `Fan` は 自機 の 方 へ 幅 120° の 扇
- 腕 の 名前 が `PatternSpec` の `Radial` と ぶつかる ので、型 名 で 書かせる

## 生む 遺伝子（`Spawner`）

- `Trail` は 飛びながら 左右 へ 撒く。画面 を 抜けた 弾 は 撒かない ので、横切る コマ数 より 長く 書かない
- `Burst` は 止まって 横 へ 一列 撃って 消える
- 種 1 以上 は 9 通り の 並び の 表 を 引く。種 0 は 軸 から 組む

## 終わり（`Terminal`）

- `Plain` は そのまま 飛ぶ
- `Relaunch` は 止まって、待って、加速 する
- `Fall` は 待って から 下 へ 引かれる。accel は 面 の 縦横 で 効く ので、どの 向き に 撃たれて も 下 へ 落ちる
- 落ち が 先 に 決まる（落ち 1 以上 で `Fall`、でなければ 止まる 感じ 1 以上 で `Relaunch`）

## 振り（`Drift`）

Trail の 撒く 向き を 回す。`Sweep` は Trail が 1 本 の 間 に 回る 角（度）で、目盛り 0 / 1 / 2 が 0° / 48° / 96°。

1 発目 の sequence の 起点 は 走らせ役 で 違う（この Core は 0、libBulletML は 自機 の 向き）。1 組目 だけ relative で 撃って、どちら でも 親 の 進む 向き に 揃える。

## 撚り（`Strands`）

Trail の 糸 の 本数 1 / 2 / 3。同じ 向き に 速さ 違い を 重ねる。倍率 は 等差 なので、2 発目 から は 前 の 弾 に 刻み を 足す `speedSeq` の `repeat` に 畳む。狙い 直す 弾 は 止まって 自機 へ 向き 直す ので 撚って も 同じ 所 に 集まり、1 本 だけ 撃つ。

## 落ち（`Fall`）

`accel vertical` は 縦 の 速さ を `FALL_TERM` で -v から g まで 直線 に 変える。折り返す まで に 上がる のは v × tr / 2。`fallHoldOf` は 真上 へ 撃たれた 葉 が `RISE_ROOM`（敵 の 高さ 80 から 余白 16 で 64 px）を 越えない 待ち を 出す。

## 入れ替え（`Alternate`）

振り の 向き を 筋 と 波 で 入れ替える。

- 根 は 符号 の 違う 2 波 を 1 組 に して `(n + g × $rank + 1) / 2` 回。走らせ役 は 回数 を 切り捨てる ので、端数 の とき 1 波 増える
- `wave` の action に 波 の 符号 を `$1` で 渡し、奇数 本目 は `0 - $1`
- 1 波 は、符号 が 筋 の 番号 で 交互 に なる ので 2 本目 から 2 本 ずつ `repeat` に 畳む。並べて 書く と 放射 12 本 × 2 波 で 字 が 12,729 字 に なった
- Bar は `top` が 終える と 頭 から 走り 直す ので、周 を またぐ 符号 は 2 周 を 1 つ に 書いて 持つ
- 入れ替え が 無ければ 何 も 渡さない（字 を いま の まま に する）

## 扇（`Fan`）

自機 の 向き から 幅 120°。2 本 は 自機（真下 180°）から ±60° ＝ 120° と 240°。

## `FLY_SPAN`（180）

止まる 段 が 飛ぶ 距離 の 合計（px）。1 段 ずつ 遠く へ 出る ので、段 が 多い ほど 1 段 を 短く する。1 段 60 コマ で 固定 した とき、3 段 目 は 画面 の 外 で 止まって 撒かなかった。

## `aliveBound`

同時 に 居る 弾 の 上界（`$rank = 1`）。根 は 繰り返す ので、段 ごと に 1 周 の 数 と 重なる 周 の 数 を 掛けて 足す。

- 系譜 まるごと の 寿命 で 掛ける と 実測 / 見積もり が 0.3 まで 下がり、`fit` が 削り すぎた
- 画面 を 抜ける 距離 を `FIELD_SPAN` で 取る ので、下向き に 長く 飛ぶ ぶん は `SAFETY` が 持つ

## `BUDGET`（10,000）

`$rank = 1` で 同時 に 居る 弾 の 上界 を ここ まで 削る。面 の 天井 と 同じ 10,000。

- 上界 は 実測 を 下回らない（81 通り の 試験 が 見る）ので、余白 を 別 に 取らない
- 6,000 に した とき は 上界 が 実測 の 1.5〜6 倍 で、Trail が 2 回 まで 削られた

## 削る 順（`shrink`）

`fit` は 上界 が `BUDGET` に 収まる まで、次 の 順 に 1 つ ずつ 削る。

1. 波 の 待ち を 倍 に（360 未満 の 間）
2. Trail の 回数 を 半分 に（4 より 多い 間）
3. Bar の 列 の 回数 を 半分 に
4. 一列 の 難度 の 伸び を 1 減らす
5. 一列 の 発数 を 1 減らす
6. 2 列 を 1 列 に
7. Trail の 回数 を 半分 に（2 より 多い 間）
8. 波 の 待ち を 倍 に（1440 未満 の 間）

- 軌跡 は 4 回 まで 残して 後回し。先 に 削る と 3 世代 の 並び で 2 回 に なり、線 に 見えなかった
- 波 を 減らす 手 は 無い。1 周 が 半分 に なる と 周 も 半分 に なり、重なる 周 が 倍 に なる

## 較正

| 変異 | 赤 に なった 試験 | 備考 |
| --- | --- | --- |
| 種 0 の 並び を 全部 Trail に | Trail は 1 回 まで / 種 0 は 軸 から 組む | |
| Trail の 回数 の 画面 の 上限 を 外す | Trail は 画面 を 横切る 時間 で 止める | |
| Burst の 一列 から 難度 を 外す（2 か所） | Burst の 一列 は 難度 で 伸びる / 難度 が 間隔 と 発数 に 入る | |
| 止める 速さ を 0 に | 止める 速さ は 0 に しない | 直角 は 緑。0 でも 向き は 残る |
| Relaunch の 加速 を 消す | Relaunch は 止まって から 動く / 81 通り | 止まった 弾 が 溜まる |
| 上界 から 重なる 周 を 外す | 81 通り | |
| Bar の 周 の 待ち を 1 に | Bar の 発射台 は 周 に 1 度 | |
| 狙い 直す 弾 の 向き 直し を 消す | 自機 に 届く / 軸 が 1 以上 | |
| Burst の 先頭 を 狙う 弾 に しない | 自機 に 届く / 軸 が 1 以上 | |

| Trail の 狙う 組 を 普通 の 弾 に | 軸 が 1 以上 | 定義 だけ 見て いた とき は 緑 だった |

| 奇数 本目 の 符号 を $1 に | 入れ替え は 左右 を 鏡写し に する | |

| 扇 の -60 を -30 に | 扇 は 自機 の 向き から 幅 120° | |
| 上界 から 撚り の 本数 を 外す | 撚り と 落ち は 上界 に 入る | |
| 落ち の 寿命 を Plain と 同じ に | 撚り と 落ち は 上界 に 入る | |
| 終わり の 順 を Relaunch 先 に | 終わり は 落ち が 先 | |
| 引数 を 常に 渡す | 入れ替え が 無ければ 引数 を 渡さない | |

### 81 通り は 面 の 天井 に 収まる

81 通り（並び 9 × 終わり 3 × 根 3、撚り 3 本・振り 96°・入れ替え あり）を 難度 1 で 走らせた 最大数。610 コマ で 見て いた とき は、その 後 に 最大 が 伸びる 並び が 26 本 在った ので 700 コマ 見る。

| 走らせた 長さ | 記録 |
| --- | --- |
| 700 コマ | 最大数 の 最大 7,918 発、実測 / 見積もり の 最大 0.829（どちら も T・Plain・Bar） |
| 1,000 コマ | 最大数 の 最大 8,379 発（794 コマ 目）、実測 / 見積もり の 最大 0.877（T・Plain・Bar）。700 コマ より 後 に 伸びた 並び が 12 本、998 コマ 目 で まだ 伸びる 並び も 在る（落ち着いて いない） |

- 字 の 大きさ の 最大 7,419 字（B → B → T・Relaunch・Bar）
- 上端 の 帯（y < 8）に 居た 弾 の 延べ 数（葉 を 1 発 ずつ 追う 口 が 無い ので 目安）：落ち あり の 最大 13,182、落ち なし の 最大 61,668
- 根 は 繰り返す。重なる 周 を 見積もり に 入れる 前 は 実測 / 見積もり が 4.1 倍、最大数 は 18,512 発 だった
