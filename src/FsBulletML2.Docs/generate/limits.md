# 上限（`Consts`）

生成器 が 守る 上限 と、その 値 に した 理由。`Exprs` と `Bound` の 両方 が 引く。

## `MAX_ALIVE`（900）

同時 に 画面 に 居る 弾 の 上限。`Generate` が 組んだ 木 に ついて の 約束 で、`Edit`（段・仕掛け・混ぜ・散らし）を 通した あと は 誰 も 約束 して いない。

- 素 の 生成 は ほぼ 守る。14 軸 を 振った 120 通り を 300 コマ 走らせて、900 超え は 4 本、最大 1,080 発。実測 / 上界 は 最大 1.72・中央 0.72
- 越える のは `Edit` の 層。`Tune.applySteps` の `split` は 葉 を 4 発 に 割って 親 を 消す ので、1 段 で 約 4 倍 に なる（収録 4 本 の 実測 で 2.6〜4.1 倍）
- 面 を 通した 天井 が 要る 側 は、そちら で 別 に 数 を 置く

## `FIELD_SPAN`（280）

弾 が 画面 を 抜ける まで に 進む 距離。面 は 480x640 で、撃つ のは 中ほど から なので、端 まで は 240〜320。その 間 を 取った。

速い 弾 は `BULLET_LIFE`（180 コマ）より 先 に 画面 から 出る。これ を 見ない と 上界 が 3 倍 過大 に なり、`fit` が `wait` を 7 倍 に 伸ばして「速い が スカスカ」な 弾幕 が 出た（実機 で 踏んだ）。
