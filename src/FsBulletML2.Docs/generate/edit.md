# `Edit` の 層 の 予算 と 散らし の 間隔

`Edit`（段・仕掛け・混ぜ・散らし）を 通した あと の 弾数 と、散らした 弾幕 の 走行。試験 は `EditBudget` と `ScatterPacing`。

## `EditBudget`

`Consts.MAX_ALIVE`（900）は `Generate` が 組んだ 木 に ついて の 約束 で、`Edit` の 層 は 誰 も 約束 して いない。約束 が 無い こと を 数 で 固定 する。

ここ を 門 に する のは、増えて も 気づかない から。面 の 側 は 別 の 天井（DanmakuLab の `FIELD_ALIVE`）で 受ける ので、その 数 を 決め直す とき に この 倍率 が 材料 に なる。

300 コマ の 最大 同時数 を 5 つ の 型 で 測った 実測:

| 型 | 素 | 段 1 | 倍 | 段 2 | 倍 | 層 1 | 倍 |
|---|---|---|---|---|---|---|---|
| Spiral | 427 | 2890 | 6.77 | 10204 | 23.90 | 427 | 1.00 |
| Radial | 400 | 2775 | 6.94 | 9893 | 24.73 | 400 | 1.00 |
| Aimed | 620 | 2881 | 4.65 | 10597 | 17.09 | 620 | 1.00 |
| Spread | 562 | 2872 | 5.11 | 10535 | 18.75 | 562 | 1.00 |
| Curtain | 623 | 2993 | 4.80 | 11100 | 17.82 | 623 | 1.00 |

床 は 実測 の 最大 に 3 割 の 余白。推測 で 置かない。6 と 20 で 書いたら 6.77 と 23.90 で 落ちた。

層 は 木 を 変える（字 が 1,476 から 2,197 へ）のに 同時数 が 1.00 倍。空振り では ない こと は 字 の 長さ で 確かめた。なぜ 増えない か は 測って いない。

### 較正

| 変異 | 赤 に なった 試験 | 備考 |
|---|---|---|
| `splitBranch` の `times` を 4 から 8 に | `段 を 1 つ 足す と 弾数 が 9 倍 を超えない`・`段 を 2 つ 足して も 弾数 が 32 倍 を超えない` | |
| `applySteps` を 素通し に | 3 点 とも | |
| `layer` を `axis` から 外す | `層 は 同時数 を増やさない` | |
| `MAX_SPLIT` を 3 から 5 に | 赤 に ならない | `split` は 2 まで しか 来ない（jev の `steps` が 0..2）ので、深さ 3 の 頭打ち に 当たる 材料 が 無い |
| `MAX_SPLIT` を 3 から 1 に | 赤 に ならない | 倍率 が 減る 向き なので、上限 だけ 見る 門 は 通す |

## `ScatterPacing`

`ScatterSeeds`（Core.Tests）は 木 の 字 を 見る。ここ は 走行 を 見る。1 コマ の ずれ も、余計 に 待つ 20 コマ も、XML には 出ない。

`paced` の 輪 の 実測：wait 20 は 20 コマ / changeSpeed term 20 は 19 コマ / accel term 20 は 1 コマ。

`散らして も 弾数 が 跳ねない` で `Depth` を 2.0 に する のは、ここ が 散らせなかった 軸 だから。直す 前 は 5 つ の 型 とも depth 1.0 以上 で 1 か所 の まま だった。弾数 の 比 は 直す 前 は 708 倍 だった。

### 較正

| 変異 | 赤 に なった 試験 | 備考 |
|---|---|---|
| `changeSpeed` を `Wait term` に | `散らして も 1 周 の コマ 数 が変わらない` | 1 コマ ずれる |
| `accel` を `Wait term` に | `散らして も 1 周 の コマ 数 が変わらない` | 余計 に 待つ |
| `ghost` を いつも `Some []` に | `散らして も 1 周 の コマ 数 が変わらない`・`散らして も 弾数 が 跳ねない` | |
| `split` の `spends g` を true に 固定 | 赤 に ならない | `ScatterSeeds`（Core.Tests）の `waitless` と `nested` が 捕まえる |
| `spends` の 再帰 を 落とす | 赤 に ならない | 同上 |

上 の 3 つ は XML を 見る 門 では 1 つ も 赤 に ならない。1 コマ の ずれ も、余計 に 待つ 20 コマ も、字 には 出ない。

下 の 2 つ が ここ で 赤 に ならない のは、`paced` も 生成 した 型 も 写し が 上っ面 に 待ち を 持つ ので 変わらない から。
